Maps PHP values to other types described with **TypeLang** syntax.

Full documentation is available at [typelang.dev](https://typelang.dev).

## Installation

Install the package via [Composer](https://getcomposer.org):

```sh
composer require type-lang/mapper
```

**Requirements:** 
- PHP 8.1+
